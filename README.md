# Sprint_6
# Автотесты для Яндекс.Самокат

Проект автоматизации тестирования учебного сервиса «Яндекс.Самокат» для курса Яндекс.Практикум.

## Технологии

- **Python 3.13**
- **Selenium 4.15.0** - автоматизация браузера
- **Pytest 7.4.0** - фреймворк для тестирования
- **Allure 2.13.2** - создание отчетов
- **Page Object Pattern** - архитектура проекта
